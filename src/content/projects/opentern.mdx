# OpenTern

At the height of internship season, I was looking for a way to simplify my application process. I was sick of swapping tabs between job databases, spreadsheets, and job websites. After a bit of searching, nothing existed that matched my needs so I made it myself.

Opentern is a web application that scrapes GitHub repositories that store job listings, stores that data in a database, and lets users quickly add those listings to their own job application lists.
